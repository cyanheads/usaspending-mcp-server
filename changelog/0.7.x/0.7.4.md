# 0.7.4 — 2026-11-25

## Added

- **`usaspending_search_awards`** filters by `extent_competed_type_codes`, `set_aside_type_codes`, and `contract_pricing_type_codes`, flat and in `filters`. They echo as `applied_*`, and an assistance award type beside them fails as `contract_filters_type_mismatch` ([#119](https://github.com/cyanheads/usaspending-mcp-server/issues/119)).
- **`usaspending_search_awards`** returns `matches_by_group`, the matches in every award-type group, beside `page_metadata.total` for the single group searched; the notice names other groups that match. The group count is cut when it runs 2 seconds past the search and the total count, and `matches_by_group` is then listed in `unavailable_sections` as `api_timeout`, retryable ([#125](https://github.com/cyanheads/usaspending-mcp-server/issues/125)).
- **`usaspending_get_award`** returns `recipient.executive_compensation`, `office_name`, `subtier_code`, and `subtier_abbreviation` on `awarding_agency` and `funding_agency`, `funding_agency.toptier_slug`, and, on assistance awards, `non_federal_funding`, `total_funding` (absent on loans), and `funding_opportunity` ([#130](https://github.com/cyanheads/usaspending-mcp-server/issues/130)).
- **`usaspending_search_recipients`** accepts `name`, `recipient_name`, and `search_text` as aliases of `keyword` ([#134](https://github.com/cyanheads/usaspending-mcp-server/issues/134)).
- **`usaspending_autocomplete_filters`** accepts `type: "funding_agency"` ([#133](https://github.com/cyanheads/usaspending-mcp-server/issues/133)).

## Changed

- **`usaspending_get_award_transactions`** caps `limit` at 5,000, the upstream maximum (was 2,000) ([#129](https://github.com/cyanheads/usaspending-mcp-server/issues/129)).
- **Tool descriptions** state each repeated description once per tool; nested twins point at the top-level field. `usaspending_search_awards` is 29,380 → 29,943 bytes in `tools/list` (its `inputSchema` 16,632 → 14,708, with the three new filters); `usaspending_spending_by_geography` 17,930 → 17,329, `usaspending_spending_by_category` 17,033 → 16,581, `usaspending_spending_over_time` 15,544 → 15,070 ([#131](https://github.com/cyanheads/usaspending-mcp-server/issues/131)).
- **`usaspending-guide` 1.3 → 1.4** covers the contract filters, group counts, and funding-agency lookup.

## Fixed

- **`funding_agency_name`** resolves against USAspending's funding-agency directory instead of the awarding one, so funding-only agencies verify and their abbreviations resolve ([#133](https://github.com/cyanheads/usaspending-mcp-server/issues/133)).
- **Award type descriptions** on the three spending analytics tools list the F001–F010 financial-assistance codes their input already accepted.
- **`usaspending_get_agency`, `usaspending_get_recipient`, and `usaspending_search_awards`** list a secondary request USAspending throttles (HTTP 429) in `unavailable_sections` as `api_unavailable`, retryable, instead of `upstream_error`.
- **Agency names** are trimmed before lookup, so a padded name resolves; a whitespace-only name is ignored like an empty one instead of failing with an upstream 400, and in award search a blank nested name falls back to the flat one.
