# 0.4.3 — 2026-09-20

## Added

- **`AGENTS.md`** — the agent-protocol twin of `CLAUDE.md`, byte-identical and shipped in the npm package. Agents that read `AGENTS.md` were previously left without a protocol file.
- **`bun run audit:fix`** (`bun audit fix`) — the first step of transitive-advisory triage, ahead of `bun update <name>`, `bun dedupe`, and `audit:refresh`.

## Changed

- **The framework skill tree moved from `skills/` to `framework-skills/`.** Claude Code and Codex auto-load a plugin's root `skills/`, so this server's `.claude-plugin/` and `.codex-plugin/` manifests handed its development skills to every agent that installed it. The `.claude/skills/` mirror keeps its name.
- **`createApp({ sessionMode: 'stateless' })` declares the session posture in `src/`**, where `.env.example`, the `Dockerfile`, and the README table already set it. `MCP_SESSION_MODE` still wins when it carries a meaningful value.
- **Every `errors[]` entry the service layer produces carries `thrownBy: 'service'`** — `api_unavailable` and `api_timeout` on all 18 tools, which `usaspending-service.ts` throws as `serviceUnavailable(...)` and `timeout(...)`.
- **Handler-local `ctx.fail` sites forward `ctx.recoveryFor(<reason>)`** instead of restating the declared `recovery` as a divergent inline hint, so one text reaches both the advertised contract and the wire. `usaspending_autocomplete_filters` keeps an explicit hint, which quotes the caller's own `search_text`.
- **`usaspending_get_agency`'s `missing_input` recovery names `usaspending_list_agencies`** alongside the two accepted argument shapes.
- **Tool error responses change on three points a client may branch on.** An argument the schema rejects returns `InvalidParams` (`-32602`) where it returned `ValidationError` (`-32007`), carrying `data.reason: "invalid_arguments"` and a hint naming the offending field. Any error whose data carries a `reason` or a boolean `retryable` closes its text with `(reason <reason> · not retryable)`. A USAspending 500 or 501 is `ServiceUnavailable` and is retried, where a 500 previously failed on the first attempt. Match error text by substring rather than byte-exact; `structuredContent` is otherwise unchanged.
- **Bun engines floor raised to `>=1.4.0`**, required by the framework since 0.12.9.
- Shipped skills resynced to the framework's current versions, including `add-tool` 2.20 → 2.29, `api-errors` 1.7 → 1.15, `api-linter` 1.12 → 1.17, `release-and-publish` 1.11 → 2.19, and the new `release-pr-review` 1.4.

## Fixed

- **A caller-initiated abort classifies as `RequestCancelled` (`-32011`), not `InternalError`** — the framework stopped hand-building an `InternalError` on `fetchWithTimeout`'s external-abort path in 0.12.4. The service's own budget `Timeout` is unaffected; only a caller that went away changes code.
