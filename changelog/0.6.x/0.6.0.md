# 0.6.0 — 2026-10-24

## Added

- **Federal-account tools** accept optional `fiscal_year` across search, detail, and breakdowns, return reporting periods, and retain empty selected years with a notice (#97).
- **`usaspending_get_award`** exposes district, county, recipient ZIP, federal-account totals, DEF-code outlays, and exercised-options values when supplied (#87).
- **`usaspending_get_award_transactions`** returns populated loan face values, original subsidy costs, and assistance `cfda_number` values (#90).
- **`usaspending_list_agencies`** supports optional pagination with the full directory total and `has_next`, preserving the full-list default (#98).

## Changed

- **`usaspending_get_award_transactions`** returns string transaction IDs and removes unsupported `recipient_name` and `awarding_agency_name` output fields (#90).
- **`usaspending_autocomplete_filters`** uses the replacement agency endpoint, preserves agency tiers and parent identities, and exposes optional `subtier_code` (#85).

## Removed

- **`usaspending_get_award_subawards`** removes unsupported `recipient_uei` and `place_of_performance` output fields (#96).

## Fixed

- **`agency_name`** matches top-tier and sub-tier names across award search and spending analytics; shared sub-tier names match under every parent (#84).
- **`usaspending_list_agencies`** returns provider fiscal-year and quarter labels and describes amounts as the latest reported period (#92).
- **Markdown output** preserves upstream strings through client parsing, including punctuation in names, descriptions, notices, and table values.
- **Development guidance and audit classification** follow the adopted framework; hosted-client examples use each client's configuration shape.
