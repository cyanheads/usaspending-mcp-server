# 0.4.5 — 2026-10-07

## Changed

- **Tool errors carry a request ID.** `data.requestId` is set on every error result and the text content ends with `request <id>` (mcp-ts-core 0.13.10).
- **Recovery hints come from each tool's declared `errors[]` entry**, filled by the framework (mcp-ts-core 0.13.10). Handlers and the upstream-failure classifier no longer forward them; the hint text callers see is unchanged.
- **Error `data` no longer carries server stack traces, request context, or `rootCause`** (mcp-ts-core 0.13.7, 0.13.8, and 0.13.13 respectively).
- **A JSON-stringified object, or an integer sent for a string field, is repaired before validation** instead of rejected (mcp-ts-core 0.13.9).
- **An upstream non-2xx response without a JSON `detail` names the endpoint by origin only** (`https://api.usaspending.gov/…`); a timeout message still names the endpoint path (mcp-ts-core 0.13.12).
- **`server.json`:** npm entries drop the `run start:*` package arguments and set `runtimeHint: "npx"`; the `streamable-http` entry fixes `MCP_TRANSPORT_TYPE` as `value: "http"`, so a registry install that picks HTTP starts HTTP (matches the mcp-ts-core 0.13.11 scaffold).
- **Docker image:** production dependencies install in a `deps` stage on the build platform (mcp-ts-core 0.13.10), musl-only packages are pruned (0.13.11), and the base image is Bun 1.4.2 (0.13.7). `scripts/install-otel.ts` and `scripts/prune-musl-packages.ts` are new.
- **MCP SDK** `@modelcontextprotocol/server` ^2.2.0 via the framework (^2.1.0 in 0.13.9, ^2.2.0 in 0.13.11).
- **Package scripts:** `start`, `start:stdio`, and `start:http` run `node dist/index.js`; `test` runs `vitest run`; `rebuild` calls `scripts/build.ts` directly; `files` excludes `dist/*.mcpb`.
- **Repo config:** CodeQL runs one matrix job per language (`actions`, `javascript-typescript`), `.gitignore` and `.dockerignore` cover every `.env*` variant, `.mcpbignore` excludes `docs/idea.md`, `logs/`, and `.cache/`, and the devcheck, packaging, skill-version, and release scripts match the framework templates.
- **Docs:** the README environment table lists `LOG_TOOL_FAILURE_PAYLOADS` and `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT`, `.env.example` documents `MCP_REQUEST_STATE_KEY`, the Bun and MCP SDK badges are current, and `framework-skills/` is synced to 0.13.13.
