# 0.4.2 — 2026-08-24

## Added

- **Protocol revision `2026-07-28` is served on every HTTP endpoint**, alongside the existing 2025-era revisions — a 2025 client keeps working unchanged.
- **`tools/list` carries a cache hint** — the tool surface is 18 compiled-in definitions with no dynamic registration or per-caller filtering, so it changes only on redeploy. `cacheHints: { 'tools/list': { ttlMs: 3_600_000, cacheScope: 'public' } }` lets a 2026-era client cache it for an hour; 2025-era clients are unaffected.

## Changed

- **Breaking: tool arguments are strict.** Every tool's advertised `inputSchema` now carries `additionalProperties: false`, and an argument key a tool's schema doesn't declare is rejected by name (`Unrecognized key: "..."`) instead of being silently dropped. A call that previously succeeded with an extra or misspelled key — its filter never applied — now fails instead of returning results the caller misread as filtered.
- **The advertised `outputSchema` declares the error envelope** — success fields are optional and `error` is a declared member. A client that validates `structuredContent` without checking `isError` no longer rejects error results.
- **`MCP_SESSION_MODE` is explicit `stateless` on every surface that sets it.** `.env.example` previously left the variable commented out, resolving through `auto` to `stateful`, while the Dockerfile already set `stateless` — a container and a source run served different session modes. `.env.example` now ships uncommented with `stateless` and documents all three accepted values (`auto` / `stateful` / `stateless`) and the real default; the README configuration table gains a row for it.

## Fixed

- **The production Docker image no longer pulls the framework's optional peer dependencies** (test runner, service SDKs, parsers) — `bun install --production` now passes `--omit=peer`, so only what this server actually imports lands in the image; the OTel install step carries the same flag so it doesn't re-resolve the graph and pull them back in.

## Dependencies

- `@cyanheads/mcp-ts-core` `^0.11.0` → `^0.12.3` — nine releases, including the SDK v2 migration in 0.12.0 (`@modelcontextprotocol/sdk` + `@hono/mcp` replaced by `@modelcontextprotocol/server` + `@modelcontextprotocol/client`, `ctx.elicit` replaced by `ctx.requestInput`/`ctx.inputs`, the experimental tasks surface removed).
- `bun` `1.3.14` → `1.4.0` (`packageManager`, `Dockerfile` base images).
- `@biomejs/biome` `^2.5.5` → `^2.5.10`, `@types/node` `^26.0.0` → `^26.2.0`, `ignore` `^7.0.5` → `^7.0.6`, `tsc-alias` `^1.8.17` → `^1.9.2`, `vitest` `^4.1.9` → `^4.1.11`.
