# 0.7.3 — 2026-11-13

## Added

- **`funding_agency_name`** filters award search and all three spending analytics tools. Supply both agency roles to match their intersection ([#127](https://github.com/cyanheads/usaspending-mcp-server/issues/127)).
- **`usaspending_autocomplete_filters`** accepts `type: "def_code"` to find Disaster Emergency Fund codes by exact code, title, or public law ([#123](https://github.com/cyanheads/usaspending-mcp-server/issues/123)).
- **`usaspending_get_recipient`** accepts `fiscal_year: "all"` for profile totals and child recipients over all available fiscal years ([#126](https://github.com/cyanheads/usaspending-mcp-server/issues/126)).

## Changed

- **`usaspending-guide` 1.2 → 1.3** covers agency-name verification, parent attribution, recipient periods, and DEF code discovery.

## Fixed

- **`usaspending_get_agency`** aligns DEF codes with the returned budget year, labels it with `def_codes_fiscal_year`, and reports when the year-specific list is unavailable ([#120](https://github.com/cyanheads/usaspending-mcp-server/issues/120)).
- **Award search and spending analytics** resolve case-insensitive agency names and unambiguous abbreviations. Responses echo the names sent and disclose when a name could not be verified ([#121](https://github.com/cyanheads/usaspending-mcp-server/issues/121)).
- **`usaspending_search_recipients`** labels the precomputed obligations on every page as trailing 12 months ([#122](https://github.com/cyanheads/usaspending-mcp-server/issues/122)).
- **Spending analytics** explain the attribution scope of parent recipient IDs and point callers to returned child or standalone IDs for the entity's own awards ([#124](https://github.com/cyanheads/usaspending-mcp-server/issues/124)).
- **Award search, category, and geography spending** disclose when no date filter was sent and echo applied award-type codes. Award search also echoes the applied recipient name ([#128](https://github.com/cyanheads/usaspending-mcp-server/issues/128)).

## Dependencies

- **`@biomejs/biome`** ^2.6.6 → ^2.6.7 (dev)
